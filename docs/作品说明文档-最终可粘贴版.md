## 创意描述（≤100 字）

iKnow 是主动感知专注状态的 AI 考伴：摄像头抓拍 + 手表心率/HRV 协同，云端多模态识别"在做什么"，规则引擎做绿黄红分级干预；AI 拆解目标、随时答疑，生成五维专注画像与复盘。

## 介绍文档

### 1. 创意背景：行业痛点与用户需求分析

考研、考公等长期备考中，独自学习者有四大痛点：**自制力弱、缺陪伴、目标模糊、无复盘**。Focusmate 等真人陪伴产品依赖用户规模，冷启动与非高峰时段难以匹配。2026 年 7 月施行的《人工智能拟人化互动服务管理暂行办法》，对 AI 身份透明、生物特征授权与数据删除权提出明确要求。据此，iKnow 定位为「**主动感知型 AI 考伴**」：以感知替代被动操作，用手机摄像头与手表协同实时监测专注状态，提供分层干预与数据驱动的陪伴。

### 2. 核心功能设计：交互逻辑与技术实现路径

#### 2.1 核心交互逻辑

流程为「目标拆解 → 专注监测 → 智能干预 → AI 答疑 → 数据复盘」：

- **目标拆解**：AI 自适应追问——信息足够即直接生成**可量化任务清单**，模糊时最多追问 3 轮；清单可勾选、编辑、增删。
- **专注监测**：摄像头抓拍 2~3 秒画面短片段，由**云端多模态大模型**识别"在做什么"（做题/看书/看手机/趴桌/离开）；手表经**标准蓝牙（HRS）**提供心率与 **RR 间期**（推导 HRV）。识别状态与生理信号由**本机规则引擎**融合。
- **智能干预**：按分心持续时长三级——检测即 🟡 黄灯（短震 + 文字）；**≥60s 升 🔴 红灯**（连续震动 + 人格化语音）；**≥5min 强提醒**（语音循环、震动封顶）。设**置信度地板、升级冷却与 10 分钟 2 轻 + 1 重干预预算**；**无手表时走手机提示，不假装震动**。
- **AI 答疑**：可随时**文字**提问，答疑时段单独计时并计入复盘。
- **数据复盘**：生成单次复盘报告；累计 **N≥3** 次生成**五维画像**（效率 / 专注度 / 稳定性 / 执行力 / 抗干扰）与优化建议。

#### 2.2 技术实现路径

基于 **HarmonyOS NEXT + ArkTS / ArkUI** 原生开发。**多设备接入**：蓝牙（`@kit.ConnectivityKit`，标准 HRS `0x180D`/`0x2A37`）连接心率设备，读心率与 RR 间期并推导 HRV，动作幅度取手机加速度计。**画面识别**：`@kit.CameraKit` 抓拍后由**云端多模态大模型**识别，识别源可插拔（本机模拟源 / 云端）。**状态融合**：自研规则引擎（事件引擎 + 状态机），完成去抖、冷却、干预预算与**崩溃 / 后台恢复**（每 10s 快照，30min 内可续）。**AI 能力**：统一 `AIService` 门面对接 **OpenAI 兼容 `/chat/completions`**（千问），强制 **JSON Schema 校验**、超时重试与本地兜底，**AI 失败不影响计时与记录**。**存储**：`@kit.ArkData` RelationalStore（RDB）。**触达**：振动 + 预置人格化语音 + **元服务卡片**（今日卡 / 长期卡）。

**表1：技术实现路径**

| 模块 | 技术栈 | 用途 |
|---|---|---|
| 客户端 | HarmonyOS NEXT + ArkTS / ArkUI | 主应用与专注交互 |
| 多设备通信 | 蓝牙（`@kit.ConnectivityKit`，标准 HRS） | 心率 / RR；动作取手机加速度 |
| 端侧事件驱动 | 自研事件引擎（`WatchEventEngine`） | 融合心率 / RR / 加速度，触发识别 |
| 画面识别 | 云端多模态大模型（千问-VL） | 识别"在做什么" |
| 状态融合 | 自研规则状态机（去抖 / 冷却 / 预算） | 输出绿 / 黄 / 红与干预决策 |
| AI 与复盘 | `AIService` 门面 + OpenAI 兼容 `/chat/completions` | 规划、答疑、复盘、语录 |
| 数据存储 | `@kit.ArkData` RelationalStore | 本机会话 / 生理 / 复盘数据 |
| 消息与触达 | 元服务卡片 + 振动 + 预置人格化语音 | 桌面展示与分级提醒 |

#### 2.3 合规与隐私保护

四项落地：**身份透明**（固定显示「AI 智能体」标签并开场告知）；**分项授权**（相机 / 心率设备 / 振动独立授权，不打包勾选，未授权降级为"仅计时"）；**数据最小化**（画面**仅在触发时上传做一次性识别**、云端不留存，**生理数据不出设备**）；**数据删除权**（分项与一键清除）。

### 3. 市场前景评估

覆盖考研、考公与职场深度自学者，规模数千万级。相较番茄钟类工具，iKnow 提供多设备**主动感知**与分级干预；相较真人陪伴产品，AI **7×24 可用**、无冷启动；相较通用 AI 助手，专注行为管理更垂直。商业化：基础功能免费，人格定制与深度报告订阅增值，后续拓展企业与教育 B 端场景。

### 4. 阶段规划

**MVP（已完成）**：核心闭环 + 云端多模态识别 + 规则状态机 + 合规底座。**V1（已完成）**：蓝牙心率接入、五维专注画像、元服务卡片。**V2（规划中）**：端侧视觉模型、小艺语音入口、B 端合作。
