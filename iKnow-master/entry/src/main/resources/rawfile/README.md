# rawfile —— 分心提醒音频（可选兜底）

**正常情况下这里不需要放任何东西。**

分心提醒语由**系统语音合成**朗读（`@kit.CoreSpeechKit` → `textToSpeech`，按离线模式请求），
文案随考伴人格变化，见 `services/FeedbackService.ets` 的 `reminderText()`。

只有在**语音合成引擎建不起来**时（设备没有该能力、离线中文音色未安装等），
才会回落到这里的音频文件作为兜底。所以放不放都不影响功能，
只是"引擎不可用时也没有声音"这一种情况。

## 如果要做兜底，放两个文件（文件名必须一致）

| 文件名 | 播放时机 | 建议内容 |
|---|---|---|
| `remind_phone.wav` | 识别到「看手机」并**真正转入分心**时 | 一句短的人声，如"看到你在看手机，回来吧" |
| `remind_away.wav`  | 识别到「画面里没有人（离开）」并真正转入分心时 | 如"你还在吗？刚才没看到人" |

- 格式：`.wav` / `.mp3` / `.m4a` 都可以（AVPlayer 支持），但**文件名要与上表一致**（换扩展名要同步改 `FeedbackService.fileNameOf()`）。
- 时长建议 1~3 秒，短句即可 —— 这是"拉回来"的提醒，不是播报。
- 只录一个也行：把同一个文件复制成两个名字即可。

## 触发口径（为什么不会反复响）

提醒只在**状态机真正转入「分心」**的那一刻响一次，因此天然受这些约束：

1. 去抖：信号要持续满足才切换（见 `common/FocusTuning.ets`）；
2. 置信度地板：低于 50 的判定直接忽略（采而不信）；
3. 形态冷却：同一升级方向在冷却窗口内不重复触发；
4. 干预预算：10 分钟内最多 2 次轻干预 + 1 次重干预。

另外两类**不会出声**：

- 「趴在桌上」只算轻度分心 → 只出提示卡片；
- 「切到其他应用 + 亮屏超过 30 秒」只在回到 App 时记一条卡片（人当时不在 App 里，出声没有落点）。

语音提醒可在「我的 → 隐私与数据 → 分心提醒 → 识别到分心时语音提醒」整体关掉。
