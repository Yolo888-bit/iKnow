# rawfile —— 分心提醒语音包

## 6 个 mp3 是什么

分心提醒的**语音包**（真人录音）。文件名是**首句文字的拼音首字母**：

| 文件 | 对应文案 | 触发 |
|---|---|---|
| `strict-zssjjc.mp3` | 走神时间较长，请迅速收回注意力。 | 严格教练型 · 重度 |
| `strict-zzlcxhs.mp3` | 专注力持续涣散，请尽快进入状态。 | 严格教练型 · 重度 |
| `strict-dqztsx.mp3` | 当前状态松懈，请投入当前任务。 | 严格教练型 · 重度 |
| `gentle-zsyyll.mp3` | 走神有一会了，要不要短暂歇一下再继续？ | 温和陪伴型 · 重度 |
| `gentle-gjyxpb.mp3` | 感觉有些疲惫，想坚持还是稍微放松会儿？ | 温和陪伴型 · 重度 |
| `gentle-sxpyl.mp3` | 思绪飘远啦，休息片刻，还是接着学习？ | 温和陪伴型 · 重度 |

**文案与文件的对应关系只有一处**：`common/ReminderLines.ets`。
卡片上的文字和播出的录音都从它取，改文案/换文件只改那一个文件，不要在这里另记一份。

同一人格的 3 段**轮换播放**（避免每次都听到同一句）；卡片文字固定用第一条，
这样文字不会几秒一变、也不会和播出的录音对不上。

## 不会出声的情况（都是设计如此，不是故障）

1. **轻度（黄灯）**：语音包只有重度录音。黄灯只出提示卡片。
2. **极简安静型**：产品要求"无文字话术、无语音"，界面只显示
   `⚠️轻度分心` / `🔴重度分心` 徽标，不播任何录音。
   它原本的设计是手表轻震/强震，但当前设备没有手表 ——
   按项目"绝不假装震动"的口径，它就只有徽标。
3. **分心没持续到重度门槛**：级别按**这一次分心持续了多久**算，
   红灯要持续到 `FocusTuning.INTERVENTION_HEAVY_AFTER_MS`（当前 60 秒）
   才升级为重度，才播语音。

## 为什么需要"定期重新评估"

级别要看"持续了多久"，但干预评估原先只在状态切换那一刻跑一次 ——
那一刻时长恒为 0，永远停在轻度，重度文案和这个语音包就永远不会触发。
所以 `FocusController.recomputeTick()` 里加了定期重评
（间隔见 `FocusTuning.INTERVENTION_REEVAL_MS`）。**这两个常量不要删。**

## 想换成别的录音

直接替换同名文件即可（`.mp3` / `.wav` / `.m4a` 都支持）。
换文件名或扩展名时，改 `common/ReminderLines.ets` 里对应的 `file` 字段 —— 只改那一处。

## 触发与停止口径

**开始**：分心持续到重度门槛（红灯持续满 `FocusTuning.INTERVENTION_HEAVY_AFTER_MS`）后，
由干预事件触发一次播放，然后**一直循环**（`AVPlayer.loop = true`），
直到人回来为止 —— 不是响一句就停。

**停止**：`FocusController.syncVoiceLoop()` 在每次状态切换与心跳（1 s）检查一次，
只要不在「分心」态就停。也就是**回到专注 / 休息 / 暂停 / 答疑 / 结束本次**都会停声；
`finalize()` / `abort()` 里也显式停了一次（会话结束不能还在响）。

**为什么不会乱响**：
1. 去抖：信号要持续满足才切换；
2. 置信度地板：低于 50 的判定直接忽略（采而不信）；
3. 只对**确认分心（红灯）**震一下；「趴在桌上」这类轻度不震不响；
4. 已经在循环时新的重度事件不会重启（不会叠音）。

⚠️ 注意：**循环不再受 10 分钟干预预算约束**（预算是针对"触发一次干预事件"的）。
所以一次长时间分心会一直响，这是产品要求；要中止只能靠"回到专注"或关掉语音提醒开关。
另外，同一段专注里如果 10 分钟内第二次分心，干预预算会挡住新的重度事件 → **不会重新开始循环**。

⚠️ 模拟控制台里的**心率 / HRV / 血氧**几档注入的是「趴桌」（轻度），点了**不会有声音**。
要听语音请点「看手机」或「离开」，并让红灯**持续到门槛**之后再听。

语音提醒的**开关**在「我的 → 数据管理 → 分心提醒 → 识别到分心时语音提醒」；
**试听**在「我的 → 考伴 → 试听当前人格的提醒语音」（语音包按人格分，所以和人格选择放在一起）。
试听会**等播放真正开始/失败之后再回显**结果，不会出现"显示已播放但没声音"。
